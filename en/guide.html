Setup guide

TacLog reads the recordings in one folder on your PC. All you set up is: save recordings to a “TacLog” folder, then link that folder once.

1. FolderOBSNVIDIAAMDWindows Game BarLink the folder

Menu names may differ slightly between versions. A Japanese version with illustrations: OBS / other recorders.

1. Create a “TacLog” folder

  1. Open File Explorer and go to Videos
  2. Right-click → New → Folder, and name it TacLog (C:\Users\(you)\Videos\TacLog)

Use a dedicated folder: TacLog can delete recordings automatically after analysis.

OBS (if you stream)

  1. Settings → General → check “Automatically record when streaming”
  2. Settings → Output → set Recording Path to the TacLog folder, and Recording Quality to “Same as stream”
  3. Settings → Advanced → check “Automatically remux to mp4” (or choose MP4 / Hybrid MP4 as the recording format)

NVIDIA (NVIDIA App / GeForce Experience)

  1. Press Alt + Z → Settings → Recording (Capture / Videos)
  2. Change the save location to the TacLog folder
  3. Press Alt + F9 to start recording before the scrim, and again to stop

Instant Replay keeps only the last few minutes. Use normal recording for the whole scrim. Recordings go into a per-game subfolder; TacLog looks inside it.

AMD (AMD Software: Adrenalin Edition)

  1. Press Alt + R → Settings (gear) → Record & Stream
  2. Set the recording save location to the TacLog folder
  3. Press Ctrl + Shift + E to start and stop recording

Windows Game Bar

  1. Windows Settings → Gaming → Captures → set the maximum recording length to 4 hours
  2. Recordings are saved to Videos\Captures. Link that Captures folder in TacLog
  3. Press Win + Alt + R to start and stop recording

Captures also contains other games' clips. TacLog skips non-VALORANT videos, but if you turn on auto-delete, move videos you want to keep elsewhere.

Link the folder in TacLog

  1. Open TacLog in Google Chrome or Microsoft Edge on your PC
  2. Press the button to link the recording folder (録画フォルダを連携する) and choose the TacLog folder
  3. Allow access when the browser asks (it may ask twice)
  4. After a scrim, open TacLog: new recordings are found and analyzed automatically. Keep the page open while it works

MP4 recordings work as they are. Recordings are never uploaded.
