OBSを使わない人の録画設定

NVIDIA・AMD・Windowsの録画機能でも、TacLogで分析できます。やることは録画の保存先を「TacLog」フォルダにするだけです。配信している人は、OBSの設定ガイドのほうが自動で録画できて楽です。

1. フォルダを作るNVIDIAAMDWindowsのゲームバー最後に:TacLogと連携

画面の名前は、ソフトのバージョンによって少し違うことがあります。

1. 録画用のフォルダ「TacLog」を作る(どの録画機能でも共通)

  1. エクスプローラーを開いて、左の 「ビデオ」 フォルダを開く
  2. 何もないところで右クリック →「新規作成」→「フォルダー」
  3. 名前を TacLog にする(場所は C:\Users\(あなたの名前)\Videos\TacLog になります)

分析が終わった録画は自動で消せるので、ほかの動画と混ざらない専用のフォルダにしておくのが安全です。

NVIDIA(NVIDIA App / GeForce Experience の録画)

NVIDIAのグラフィックボードを使っている人向けです。

  1. ゲーム中か、デスクトップで Alt + Z を押して、NVIDIAのオーバーレイを開く
  2. 歯車(設定)→ 録画(または「キャプチャ」「ビデオ」)を開く
  3. 保存場所(ビデオの保存先)の 変更 を押して、さっき作った TacLog フォルダを選ぶ
  4. スクリムを始める前に Alt + F9 で 録画開始、終わったらもう一度 Alt + F9 で 録画停止

「インスタントリプレイ」は直前の数分しか残らないので、スクリム全体を録るには、ふつうの録画(Alt + F9)を使ってください。録画はゲームごとのフォルダ(例:TacLog\VALORANT)に入りますが、TacLogはその中も探すので大丈夫です。

AMD(AMD Software: Adrenalin Edition の録画)

AMDのグラフィックボード(Radeon)を使っている人向けです。

  1. Alt + R でAMD Softwareを開く(またはデスクトップで右クリック →「AMD Software」)
  2. 右上の歯車(設定)→ 録画とストリーミング(Record & Stream)を開く
  3. 録画の保存場所 の 参照 を押して、TacLog フォルダを選ぶ
  4. スクリムを始める前に Ctrl + Shift + E で 録画開始、終わったらもう一度押して 録画停止

「インスタントリプレイ」は直前の数分だけなので、スクリム全体は録画で録ってください。

Windowsのゲームバー(Xbox Game Bar)

グラフィックボードの録画機能がない人でも、Windowsに最初から入っている機能で録画できます。

  1. Windowsの 設定 → ゲーム → キャプチャ を開く
  2. 「記録する最大時間」(録画の長さの上限)を 4時間 にする(初期設定の2時間だと、長いスクリムが途中で止まります)
  3. 保存先は「キャプチャ」フォルダ(ビデオ\キャプチャ)に決まっているので、TacLogで連携するときに、この 「キャプチャ」 フォルダを選んでください
  4. スクリムを始める前に Win + Alt + R で 録画開始、終わったらもう一度押して 録画停止

「キャプチャ」フォルダには、ほかのゲームの録画やスクリーンショットも入ります。TacLogはVALORANT以外の動画を自動で見分けて読み込みませんが、「分析後に自動で削除」をオンにする場合は、消したくない動画をほかの場所に移しておいてください。

VALORANTの表示設定(分析の精度が上がります)

  • ミニマップを固定にする:設定 → 一般 → ミニマップの「回転」と「プレイヤーを中心に固定」をオフ。これで、1人の録画からチーム全員の「どこで撃ち合って勝った・負けたか」までわかります(回転していると、場所がわかるのは録画した本人の撃ち合いだけになります)
  • 画面の表示(HUD)は消さない:上の顔写真、右上のキルログ、左上のミニマップと場所の名前、下のスキル欄を読み取ります
  • 録画は画面全体をそのまま:切り取ったり、上に別の映像を重ねたりしないでください

最後に:TacLogと録画フォルダを連携する

  1. パソコンの Google Chrome か Microsoft Edge で TacLog を開く
  2. 「録画を分析」→ 「録画フォルダを連携する」 を押して、TacLog フォルダ(ゲームバーの人は「キャプチャ」フォルダ)を選ぶ
  3. ブラウザの確認で 「許可」 を押す(2回出ることがあります)
  4. スクリムのあとにTacLogを開くと、新しい録画を見つけて自動で分析します。分析中はページを開いたままにしてください

録画はMP4のままでOKです(NVIDIA・AMD・ゲームバーはどれもMP4で保存されます)。録画そのものはアップロードせず、パソコンの中で読み取ります。
